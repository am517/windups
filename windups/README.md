# windups

The main Windups repository: the standard, the shared database schema, shared settings and
anything every windup uses. Each windup lives in its own folder of the windups monorepo (first: [Jack](../jack)).

- [WINDUPS.md](WINDUPS.md): the rules every windup follows
- [NAMES.md](NAMES.md): the name registry (every windup, its role, status and build position)
- [schema/](schema/): the shared database (`~/.local/share/windups/media.db`)
- [config/windups.toml](config/windups.toml): settings shared by all windups
- [docs/communication.md](docs/communication.md): PROPOSAL, how windups talk to each other
- [TODO.md](TODO.md): timeline; [QUESTIONS.md](QUESTIONS.md): open questions for Adam
